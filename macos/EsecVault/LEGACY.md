# Legacy app source

The maintained app moved to [mscno/esec/macos/Esec](https://github.com/mscno/esec/tree/master/macos/Esec).
This source is retained for recovery of older broker-managed environments.
New releases come from Esec and contain only a local browser and the core CLI.
See [the transition guide](../../docs/standalone-transition.md) before removing
legacy keys, seals, backups, or services.
