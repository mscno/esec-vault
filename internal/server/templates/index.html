esec vault

This server moves your esec keys between your machines. It stores only ciphertext: signing in never decrypts anything.

Sign in with GitHub

Sign in to confirm a device code, review your devices and activity, or browse your projects.

Connect a machine

  1. Install esec and esec-vault.
  2. Run: {{template "cmd" (printf "esec vault login %s" .BaseURL)}}
  3. Open this server's code page and type the code your terminal shows.

Your first machine creates your account; it asks for the account creation token the server operator gave you. Every later machine needs approval from one of your devices, your recovery phrase, or an SSH-agent unlock slot.
