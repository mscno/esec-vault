An admin creates the machine and stores the key it prints as the job's or app's secret ESEC_VAULT_MACHINE_KEY:

{{template "cmd" (printf "esec vault machine create deploy --env prod --github-repo %s --github-ref refs/heads/main" .Project)}}

The job then runs its command with the keys in its environment:

{{template "cmd" "esec-vault machine run -- esec run prod -- ./deploy.sh"}}

With --github-repo, the server hands the sealed keys only to GitHub Actions jobs of that repository (and ref) that prove it with an OIDC token, so a leaked secret alone is not enough. Remove a machine with esec vault machine remove NAME.
