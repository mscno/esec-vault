Changes to sign

Changes made on these pages (who reads what, members to add or remove, machines to remove) take effect once an admin's device signs them. The server holds no key, so it cannot sign anything itself, and your device shows each change before it signs. Run on a device with your account:

{{template "cmd" "esec vault changes"}}
