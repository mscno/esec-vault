Add a person
  1. Find their numeric GitHub id: gh api users/LOGIN --jq .id.
  2. Add it to allowed_github_ids (or ESEC_SERVER_ALLOWED_GITHUB_IDS) and restart the server.
  3. On the server, print their account creation token and give it to them over a channel you trust: {{template "cmd" "esec-vault-server -bootstrap-token-for GITHUB-ID"}}
  4. They run esec vault login {{.Config.BaseURL}} on the machine with their esec identity.

The web pages never show creation tokens: with one, whoever controls a person's GitHub account could create that person's vault account before they do.
