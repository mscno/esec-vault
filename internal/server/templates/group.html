Add a machine

On the machine, ask to join; an admin lets it in from a device:

{{template "cmd" (printf "esec-vault machine join %s --server %s" .Group .BaseURL)}}

Or join it at once with an enrollment token (for autoscaling, put the token in the machine image or its secrets):

{{template "cmd" "ESEC_VAULT_ENROLL_TOKEN=esecg1_... esec-vault machine join"}}

Or create its key on your device and copy it over:

{{template "cmd" (printf "esec vault group add-machine %s web-1" .Group)}}

The machine then runs commands with the keys of every project the group reads: esec-vault machine run -- esec run prod -- ./server. A machine deleted with its disk is removed with --destroyed, which leaves nothing to rotate.
