Personal tenants belong to one GitHub account. Any onboarded, whitelisted user can create an organisation and claim an available namespace; its owners and admins are signed roles. These are vault namespaces, not verified GitHub organisations. Creating a project never claims a name.

An organisation is the acme of acme/store. Set one up to decide, signed on your devices, who belongs to it, which KMS keys its workloads may use, and its rules; only its people then create projects and groups named after it.
