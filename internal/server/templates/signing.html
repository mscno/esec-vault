Signing changes

Who may read what is signed with your user key, which only your devices hold; the server cannot sign as you. Changes you make on these pages are signed one of these ways.

Changes signed by a passkey or the server can be read only by esec-vault v0.10 or later: everyone who shares a project or machine group with you, and the group's machines, need it first.

Passkeys

A passkey (a security key such as a YubiKey, Touch ID, or your phone) signs changes with one touch each, on the signer page. It never holds your user key, and it can sign only these changes: adding members, changing what members and machine groups read, and removals. Never making anyone an admin, never keys. A member a passkey adds gets keys only once an admin's device has checked their GitHub SSH proof.
