Groups

A group is a set of people (a team, such as acme/backend) or machines (production or staging servers), or both, that read the same environments of one or more shared projects. The projects' keys are sealed once, to the group's key, which is sealed to each person and machine in it: whoever joins reads them at once, and whoever leaves gives the group a new key.

{{template "groups-list" .}}
Set up a group

On a device that holds the project's keys:

{{template "cmd" "esec vault group create acme/backend"}} {{template "cmd" "esec vault access grant acme/backend --project acme/store --env dev,staging"}}

Add people; they read what the group reads:

{{template "cmd" "esec vault group add acme/backend alice"}}

Or bring machines in, whichever suits them:

  • An enrollment token for CI jobs and autoscaled machines: use it directly as their secret ESEC_VAULT_MACHINE_KEY, or let each machine join with it. {{template "cmd" "esec vault group token acme/production autoscale --expires 90d"}}
  • On the machine itself: it asks to join, and an admin lets it in from a device after comparing the words it shows. {{template "cmd" (printf "esec-vault machine join acme/production --server %s" $.BaseURL)}}

On every machine, commands run with the keys of the projects the group reads:

{{template "cmd" "esec-vault machine run -- esec run prod -- ./server"}}
